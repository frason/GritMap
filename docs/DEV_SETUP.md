# Development Setup

## Prerequisites

- Node.js 18+ and npm/yarn
- Xcode (for iOS development)
- Android Studio (for Android development)
- Expo CLI (installed via npm)

## Initial Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Verify TypeScript:**
   ```bash
   npm run type-check
   ```

3. **Create native project files (iOS and Android):**
   ```bash
   npm run prebuild
   ```
   This generates `ios/` and `android/` directories with the native project structure.

## Running the Development Build

### iOS

```bash
npm start:ios
```

Or with Xcode:
```bash
npm run prebuild
cd ios
open GritMap.xcworkspace
# Build and run from Xcode
```

### Android

```bash
npm start:android
```

Or with Android Studio:
```bash
npm run prebuild
cd android
# Open in Android Studio and run on emulator
```

## Project Structure

- `app.tsx` - Root layout with Expo Router
- `app/index.tsx` - Home screen with MapLibre map viewer
- `app.json` - Expo configuration
- `tsconfig.json` - TypeScript configuration
- `package.json` - Dependencies and scripts
- `ios/` - iOS native project (generated by prebuild)
- `android/` - Android native project (generated by prebuild)

## Map Configuration

The app uses MapLibre React Native with OpenStreetMap vector tiles (free, open-source). The default map style is from MapLibre's demo tiles server: https://demotiles.maplibre.org/style.json

## Database

SQLite is configured via expo-sqlite and available for use. Database schema and migrations will be implemented in subsequent phases.

## Notes

- This is a development build (not Expo Go)
- All processing and data are local
- No external backend required for MVP
- iOS is the primary dev target; Android builds via emulator testing
