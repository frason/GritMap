# First tester message (DRAFT, Jason sends it himself)

Subject: Help me test GritMap, a climb pacing app for Karoo 3

Hi [name],

I'm looking for a small group of cyclists to test GritMap, a pacing app I've been building. It helps you pace a climb: you pick or define a segment, set a goal, get a power-based plan, send it to your Hammerhead Karoo 3, ride it with live guidance, then import the ride and see plan versus actual.

It is only worth your time if you have all of these: an iPhone, a Hammerhead Karoo 3, a power meter on your bike and a heart-rate monitor. Without a power meter and heart-rate monitor it cannot do its main job, so please say no if one is missing, no hard feelings.

What I'd like you to do, once, on a real ride:
1. Install the iPhone app from TestFlight: https://testflight.apple.com/join/rgnsx1PG (open it on your iPhone; it asks you to install Apple's TestFlight app first).
2. Install the Karoo extension with the install guide: https://github.com/frason/GritMap/blob/main/docs/BETA_KAROO_INSTALL.md
3. Import a ride or pick a segment (Open Segments, opensegments.org, is a free open catalog of segments), set a goal, send it to your Karoo, ride it, import the FIT file afterwards.

Good to know:
- It's an early beta. Pacing and heart-rate features are experimental and advisory, not medical advice. Ride safely first.
- On the Karoo, install over the top of any existing GritMap and never uninstall or clear its data; this version can't be rolled back.
- Known issue: the Rides or Segments list on the phone sometimes stops responding to taps. Force-quit and reopen the app.
- Not in this beta: accounts or liked segments in the app, Android, iPad.

If something goes wrong, tell me: iPhone model and iOS version, the GritMap build number, your Karoo software version and the extension version, what you did and what happened, ideally with a screenshot. Reply here or write to help@opensegments.org. Please don't post private emails or ride files publicly; I'll only ask for a ride file if I need one, and only privately.

Thank you, this helps a lot.
[Jason]
