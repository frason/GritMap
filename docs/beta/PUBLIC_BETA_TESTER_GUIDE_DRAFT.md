# GritMap beta: tester guide (DRAFT one-pager)

## Is this for you?
You need an iPhone, a Hammerhead Karoo 3, a power meter and a heart-rate monitor. If you are missing any, GritMap can match segments but cannot do what it is for; please wait.

## What we want you to do
Run the full loop once on a real ride: install the app (TestFlight) and the Karoo extension (see the install guide), import a ride or pick a segment from Open Segments, set a goal, send it to the Karoo, ride it, import the FIT, read plan versus actual.

## What is experimental
Pacing, cardiac and physiology fields are advisory training aids, not medical measurements. Pace by feel and safety first.

## What is not in this beta
Sign-in and Liked segments in the app, publishing from the app, Android, iPad, multi-segment rides on the Karoo.

## Open Segments (the website)
Open Segments is a separate free, open catalog of cycling segments. You can browse and download without an account. If you publish a segment you offer it to everyone under an open data licence and cannot edit it later; read the Terms first. Check your start and finish near private places.

## How to report a problem
Send: iPhone model and iOS version, GritMap build number (Settings screen), Karoo software version and extension version, what you did, what you expected, what happened, a screenshot. Use the TestFlight feedback button or [support address, to be created]. For a public GitHub issue never include your Apple ID, email, home address or an unredacted ride. Ride files are private; send one only if we ask and only by email.

## Known issues
Rides/Segments lists can stop responding to taps (force-quit and reopen). The Karoo holds one segment at a time.
